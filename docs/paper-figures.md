# 推荐配图

每日更新和网站重新发布时运行 `python -m tools.collect_figures`，为最新核心推荐补充一张可核对的原文图。配图按 DOI 关联，历史批次沿用同一图，不改变论文名单、顺序或批次。

支持 Nature 原文 HTML 图、开放许可 PDF 中可明确对应图注的完整嵌入图，以及 Europe PMC 开放全文的配图。拒绝推荐区缩略图、DOI 不符的图片及有单独使用限制的图。PDF 中多图或多图注无法可靠对应时保留缺图状态，不截取可能不完整的区域。

图片保存在 `data/figures/images/`，来源、图号、作者、许可、原始文件校验值及采集状态保存在 `data/figures/catalog.json`；原有人工核对目录优先。保存原始图片字节，网站发布到 `assets/figures/`，不依赖浏览器访问外站图片。自动图注明确标为“原文图注”，人工核对的中文说明标为“图解”。

成功配图复用，失败按论文隔日重试。访问限制、没有开放全文、无明确许可或格式无法识别时，卡片显示“原图暂未获取”及原文入口，不阻断论文推荐。网络请求限制来源、大小和耗时；压缩包只读取对应图，不解包到文件系统。
