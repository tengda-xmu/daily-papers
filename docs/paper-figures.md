# 推荐配图

每日更新和网站重新发布时运行 `python -m tools.collect_figures`，为推荐卡片和独立图文页补充可核对的原文图。卡片为最新核心推荐展示一张图，独立文章可使用多幅图。配图按 DOI 或已核验论文身份关联，历史批次沿用同一图，不改变论文名单、顺序或批次。

支持 Nature、Elsevier、ASME 及已核验开放全文渠道的出版社网页图，以及 Europe PMC 配图。优先选方法总览、框架或关键结果图，拒绝封面、页眉、缩略图、DOI 不符的图片及有单独使用限制的图。网页缺图时，可从核实身份与展示许可的 PDF 提取完整原图区域，保留矢量图、子图、坐标和标注；支持图注位于图上方或下方，无法可靠对应时保留缺图状态。

图片保存在 `data/figures/images/`，来源、图号、作者、许可、文件校验值及采集状态保存在 `data/figures/catalog.json`；原有人工核对目录优先。网页图片保存原始字节，PDF 图区按原样栅格化并记录页码、区域，均不重绘。网站发布到 `assets/figures/`，不依赖浏览器访问外站图片。自动图注明确标为“原文图注”，核对后的中文说明标为“图解”。论文标识别名单独保存在 `data/curated/paper-identities.json`。

核心推荐卡片每篇最多显示一幅原图，扩展卡片不显示图片；独立图文页可展示原图组和有明确依据的研究示意图。成功配图复用，失败按论文隔日重试。访问限制、没有开放全文、无明确许可或格式无法识别时，卡片显示紧凑的“原图待获取 · 查看原文”，不阻断论文推荐。网络请求限制来源、大小和耗时；压缩包只读取对应图，不解包到文件系统。

## 精读文章组图

推荐卡片仍使用上述单图规则。独立摘要和全文文章可使用多幅许可明确的原图，目录存储在 `catalog.article_entries`，与卡片图片共用校验与来源记录。采集覆盖最新核心、扩展及保留历史，不再以全文精读完成作为补图门槛；单轮耗时用尽后保留已有结果，后续继续处理。静态构建只使用已处理数据，不访问网络。

`src.article_figures.eligible_article_figures` 仅返回通过文件哈希、图片尺寸、出处和许可检查的原图，最多十二幅。文章模型只选择图 ID 并撰写经核验的中文图解，不生成原图文件。构建输出 `article-figures.json`；本机精读队列同步其公开图片并再次检查文件，供写作和图注审稿使用。私人上传 PDF 和仅限本地使用的裁图不会因此公开。

摘要稿采用 v3 `basis=abstract`，原图组可放在背景、方法、发现或局限章节，最多四组、每组最多四幅，保持完整坐标、图例和图号；网页编排组图，不拼接或改写科学图像。原图保留作者、来源页和许可，中文图解与原始图注分开显示。旧笔记或资料页可展示已核实原图及原始图注，不附未经文章审核的中文解释。

原图优先。没有可用原图且完整摘要明确描述至少两步方法关系时，应制作一幅 `kind=study`、`basis=abstract` 的研究思路示意图，页面标注“依据摘要整理的研究思路示意图（非论文原图）”。关系不明确时允许无图，不增加摘要没有报告的流程、数值或结果；摘要稿不生成后续研究方案图。全文稿保留原研究和后续建议图，v1/v2 文章继续可读。

文章审核先回查完整原摘要或正文，再按每批最多四幅实际图片复核原图与图解。只读图注或已抽取事实不算完成图像审核；图号、面板、坐标、数值和解读不符则退回修改。摘要图文的公开阅读地址与全文升级地址一致，公众号介绍仍是独立来源入口，公众号报道不替代论文证据，也不会自动获得站内转载授权。
