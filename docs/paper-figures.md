# 推荐配图

每日更新和网站重新发布时运行 `python -m tools.collect_figures`，为最新核心推荐补充一张可核对的原文图。配图按 DOI 关联，历史批次沿用同一图，不改变论文名单、顺序或批次。

支持 Nature、Elsevier、ASME 及已核验开放全文渠道的出版社网页图，以及 Europe PMC 配图。优先选方法总览、框架或关键结果图，拒绝封面、页眉、缩略图、DOI 不符的图片及有单独使用限制的图。网页缺图时，可从核实身份与展示许可的 PDF 提取完整原图区域，保留矢量图、子图、坐标和标注；支持图注位于图上方或下方，无法可靠对应时保留缺图状态。

图片保存在 `data/figures/images/`，来源、图号、作者、许可、文件校验值及采集状态保存在 `data/figures/catalog.json`；原有人工核对目录优先。网页图片保存原始字节，PDF 图区按原样栅格化并记录页码、区域，均不重绘。网站发布到 `assets/figures/`，不依赖浏览器访问外站图片。自动图注明确标为“原文图注”，核对后的中文说明标为“图解”。论文标识别名单独保存在 `data/curated/paper-identities.json`。

核心推荐每篇最多显示一幅原图，扩展阅读不显示图片。生成示意图及其构建逻辑已移除。成功配图复用，失败按论文隔日重试。访问限制、没有开放全文、无明确许可或格式无法识别时，只显示紧凑的“原图待获取 · 查看原文”，不阻断论文推荐。网络请求限制来源、大小和耗时；压缩包只读取对应图，不解包到文件系统。

## 精读文章组图

推荐卡片仍使用上述单图规则。独立精读文章可使用多幅许可明确的原图，目录存储在 `catalog.article_entries`，与卡片图片共用校验与来源记录。采集命令同时为已有全文精读的最新核心、扩展及保留历史补图，限制总耗时和单轮论文数量；静态构建不访问网络。

`src.article_figures.eligible_article_figures` 仅返回通过文件哈希、图片尺寸、出处和许可检查的原图，最多十二幅。文章模型只选择图 ID 并撰写经核验的中文图解，不生成原图文件。构建输出 `article-figures.json`；本机精读队列同步其公开图片并再次检查文件，供写作和图注审稿使用。私人上传 PDF 和仅限本地使用的裁图不会因此公开。
