# 全文精读文章

全文精读在原有逐页证据核验之后，自动生成独立科研解读文章。公开地址为 `readings/{paper_id}.html`，首页和保留历史批次链接到同一篇文章。文章约 1800–2500 字，突出实验设计和一至两条可验证研究路线。页码只用于后台核对，文章保留公式号、图号和资料缺项的实际影响。

新版文章使用 v2 核验。每项事实和实验字段保存指定页上的原文摘录，文字摘录需与页面内容匹配；扫描图表需提供原页图像和定位。文章段落、实验字段、原研究示意图及组图说明分别绑定事实依据。审稿重新读取对应正文和原页图像，检查数字、单位、样本类别、分组、比较条件及图文一致性；任何关键项遗漏或未通过都会退回修改。最终审稿仍依赖模型判断，不等同于人工复核或准确率保证。

## 内容与公开数据

`analysis.article` 保存版本化结构：导语、四个叙事章节、实验信息表、研究路线、两幅图的节点和连接，以及有来源的相关研究。`article_updated_at` 独立于原全文完成时间；`article_profile` 是文章程序版本、资料版本和启用研究方向的哈希。`src.reading_article.public_article` 对所有字段执行白名单和大小校验；图由固定 SVG 渲染器构建，模型不能插入可执行标记。

v2 增加 `figure_groups`：每组指定 `method`、`validation` 或 `findings` 章节、组标题和最多四个 `{figure_id, caption}` 面板。最多四组，不能重复使用同一原图；图 ID 必须来自已核实来源、展示许可和文件校验值的目录。组图以网页布局组织，保留原始图片、坐标、图例和原图编号；桌面最多两列、手机单列，逐图可放大。没有合格原图时保留明确标注的研究示意图，不补造图片。

`article_profile` 同时包含可用原图的指纹；新增或撤销原图会触发文章升级，并复用有效的事实缓存。v1 文章仍可读取；v2 不复用没有逐项摘录的旧事实缓存。原文摘录、`claim_evidence` 及审稿记录仅保留在本机，不随文章公开。

文章之外的旧 `deep_read` 字段继续保存，兼容已有导读、评分和推荐规则。公开数据只包含必要文章及来源，逐页事实整理、检索原始响应、模型草稿、PDF、私人笔记及对话保存在本机。两幅图分别注明本站根据论文绘制、本站提出的研究建议；它们不进入论文卡片的原图资源系统。

## 调度与恢复

现有精读队列增加独立的 `article_*` 状态、尝试次数和当前阶段。只有启用推荐论文、全文覆盖完成且资料版本匹配的任务进入文章升级。优先顺序与精读一致：最新核心、最新扩展、保留历史；用户对话继续抢占共享生成锁。

流程为逐批实验事实整理、同类检索、相关文献选择、文章与图示生成、独立事实审核、串行发布。文章阶段保存到 `.local/codex-bridge/article-drafts/{paper_id}/{article_key}/`，实验事实单独保存在 `article-facts/{paper_id}/{material_version}-v{facts_version}/`，编辑版本或研究方向变化时复用，不重复读取原页。重启和抢占保留已通过阶段。一次资料版本最多自动生成尝试三次，连接尚未建立不计入；手动重试沿用受配对保护的精读任务接口。失败不会撤销原全文精读状态，也不会覆盖已有文章。

公开文献检索默认近五年，每篇最多六次来源搜索，实际比较至多五篇具备完整摘要的研究。缓存七天；部分失败缓存一天，保留已有证据并次日再试。检索没有足够依据时允许发布原文精读及明确标注的候选方案，不把未找到结果表述为没有既有研究。检索结果后续补齐只重做文献比较和文章阶段。

## 发布与维护

新版文章通过既有 `auto-reading` 发布通道进入 `connector-data`，构建时从最新精读生成 HTML 和 SVG。所有整站更新及旧发布快照重试都会导入最新精读，保持原批次名单、编号、时间和顺序。已发布文章升级过程中继续可读；被删除批次独占的论文停止升级，其私人资料仍保留。

升级助手前在空闲时备份任务库，迁移只新增文章字段、不重置逐页阅读记录。验证至少覆盖有明确实验分组的结构生成论文、存在原文缺项的论文、含扫描页或图表的疲劳论文，并检查手机表格、两种图示布局、放大关闭和原文链接。
