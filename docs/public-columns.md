# AI 前沿与科研申请

`ai.html`、`ai-updates.json` 和 `leads.html` 是公开静态内容，手机浏览无需连接本机。导航也覆盖历史批次。AI 列表支持多标签、时间和用途筛选及 20／50／100 条分页；科研申请默认隐藏已截止项，支持企业及集团筛选。

## 来源和记录

- `config/ai-sources.json` 配置公告、更新日志和版本发布源；不采集 README 修改或仓库星数。
- `config/opportunity-sources.json` 配置官方申请来源及所属集团。集团字段来自明确的来源配置，不能从申请条件中的企业名称推断。
- `data/ai-updates.json` 和 `data/opportunities.json` 保留历史。失败的来源保留已有内容；采集、核对和原始发布日期分别记录。
- 经人工核实的结构化申请条件记录在来源的 `review` 中，只有官方正文内容摘要一致时才复用。原文更改后重新提取截止信息；不能继续套用旧条件。
- 申请延期留存更正记录。未截止机会超过 30 天未核实即标为待核对；有效申请不受发布 90 天限制，截止后保留展示 90 天。长期申请入口不代表所有岗位始终有空缺。
- 相同 URL 和明确同版本发布合并；不同版本分别保留，重新采集不改变原发布日期。公共索引只包含短摘要、来源和公开导读。

## 导读和更新

`python -m tools.public_updates --refresh` 独立刷新三个公共集合（AI、科研申请和原有科研线索）。北京时间每日 21:00 的工作流和补偿检查分别判断论文与公共栏目；论文没有新增或生成失败时，栏目仍可构建并发布。`public-updates.json` 记录各集合本轮结果。所有 Pages 发布共用已有串行锁。

优先使用配置的摘要服务。不可用时保留官方标题和摘要，显示中文导读待补充。本机助手使用独立的 `.local/codex-bridge/ai-digests/reading-queue.sqlite3` 队列补充导读，与论文精读共用串行模型锁，用户对话优先。失败最多自动尝试三次，可在设置中手动重试。配对接口为 `GET /api/ai/reading-tasks`、`POST /api/ai/reading-tasks/sync` 和 `POST /api/ai/reading-tasks/{id}/retry`。

中文说明与用法必须携带原文依据并匹配内容版本；步骤不足时留空，不猜命令、费用或效果。科研迁移用途标为建议。导读发布到 `connector-data` 中的 `data/ai-readings/`，不生成论文批次。公开发布不包含用户对话、星级、PDF、批注、登录凭证或配对数据。

新增来源时应核对其官方网站及发布单位，设置允许的域名和通知路径，再通过实际采集检查正文、发布日期、截止时间与附件。需要登录、动态加载或暂时无法访问的平台在来源状态中显示，不声称已经完整覆盖。

## 公众号与小红书

两个栏目共用 `data/social-articles.json`，先独立采集再分类，不依赖新论文批次。现有公众号订阅、手动账号、WeRSS 同步与公开索引共同参与；每天的三个公开查询在 AI、科研申请、其他线索和缺少覆盖的订阅之间轮换。已发布的历史公众号元数据会幂等登记。

小红书使用现有 `SERPAPI_API_KEY` 的 Google 网页搜索，每个北京时间自然日最多两个新查询，两个栏目各一个，缓存 24 小时；不调用 Scholar 搜索笔记。只读取无需登录即可访问的页面，没有正文时明确标为索引或短摘要。配置缺失、限额、访问限制及失败独立展示，已有记录保留。

设置中的“公众号与小红书来源”可添加笔记。配对接口为 `GET/POST /api/social-notes`、`POST /api/social-notes/preview`、`DELETE /api/social-notes/{id}` 和 `POST /api/social-notes/sync`。写入带 revision 校验，预览不保存，草稿及完整手动正文仅在 `.local/social-notes/state.json` 中。同步把短摘要和来源依据写入 `config/xiaohongshu-notes.json`，触发静态站点发布；冲突或失败保留本机草稿。手机仅浏览公开内容，无需配对。

来源记录区分平台、账号/作者、笔记标识、原始与转载日期、正文/短摘要/索引/手动补充依据。原始实践与正式发布分别展示；同一事件合并来源，独立教程保留关联。申请转载不因页面可以读取就变为已核验；只有官网对应原文或 `config/social-sources.json` 中明确核实的官方账号绑定可建立正式状态。导读引用文本必须匹配来源和内容版本，资料不足不生成步骤。

两个栏目支持平台和账号筛选。公众号及小红书内容不占论文名额；AI、任职和项目内容排除在论文热度依据之外。新增来源只公开元信息、短摘要和导读，不公开登录态或原文全文。
