来源授权与配置

公开接口自动采集；需要账号的来源完成一次授权后加入每日更新。

所有状态以实际运行结果为准。保存密钥后，请在首页点击“手动更新”，运行完成后查看来源状态。

打开 GitHub 密钥设置 返回论文推荐

Elsevier / Scopus

在 Elsevier 开发者门户登录并创建 API Key，保存为 ELSEVIER_API_KEY。机构提供 Insttoken 时同时保存 ELSEVIER_INSTTOKEN。订阅与网络权限以机构授权为准。

Google Scholar

在 SerpApi 控制台获取密钥，保存为 SERPAPI_API_KEY。系统通过 SerpApi 检索 Google Scholar；可用额度以你的账号为准。

ResearchGate

公开索引：复用已配置的 SERPAPI_API_KEY，每天检索 Google Scholar 收录的 ResearchGate 论文。默认一次查询，优先复用 24 小时缓存；只保留论文元数据和 ResearchGate 论文主页链接。页面会明确标注“公开索引已接入”，该状态不代表浏览器账号已经登录。

检索侧重大模型、智能体与三个研究方向；年份缺失的结果作为待核验线索保留，检索片段不作为完整摘要或全文解读依据。Google Scholar 的索引范围也不等于 ResearchGate 的全部论文。

指定作者主页：在自己的电脑上运行连接器，首次在它打开的独立浏览器窗口中手动登录，再继续采集。日常 Chrome 的登录不会自动同步到连接器的 Edge 会话。导出的论文元数据同步到 connector-data 分支后，GitHub Actions 优先读取近期成功导出的记录；导出缺失、过期或本期无记录时使用公开索引。

python -m pip install -r connectors/researchgate_sync/requirements.txt
python connectors/researchgate_sync/export.py --login --channel msedge --url https://www.researchgate.net/profile/Da-Teng-6
python -m tools.publish_researchgate

Windows 可直接使用已安装的 Edge。发布工具只同步论文元数据和采集时间；浏览器登录会话保留在本机。完成一次成功采集后，可启用每天北京时间 06:30 的本机同步任务，为 07:00 日报准备数据；电脑需要开机并登录 Windows。详见连接器说明。

若出现 Access restricted，表示 ResearchGate 当前限制了访问。先暂停采集，使用页面的 Log in 完成验证；若登录入口也受限，请等待恢复或联系ResearchGate 帮助中心。恢复普通访问并成功采集前，保持定时任务停用。

微信公众号

本机 WeRSS 同步：在本机管理页完成微信扫码授权，添加公众号。Windows 定时任务于 06:35 采集，再把标题、短摘要、公众号名称、日期和原文链接同步到仓库，供 07:00 日报读取。电脑需要开机并登录 Windows，微信会话失效后需重新扫码。

管理地址为本机的 http://127.0.0.1:8001/。登录会话与管理密码只保存在本机；网站通过 connector-data 分支读取元数据和采集状态，无需开放公网端口。

遇到微信 200013 限频会立即停止本轮采集，网页显示实际限频状态并保留已有数据；后续每日任务再尝试。微信公众号文章用于科研线索筛选，核心与扩展推荐仍需核验论文和中文精读。

powershell -NoProfile -ExecutionPolicy Bypass -File tools/start_wechat.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File tools/sync_wechat.ps1

本机连接器说明 · 订阅领域与筛选配置

已有远程 WeRSS：也可把 GitHub Actions 可访问的文章 RSS、Atom 或 JSON 地址保存为 WECHAT_RSS_URLS，需要请求头时配置 WECHAT_RSS_HEADERS。WeRSS 的 /feed/all.json 返回文章，根路径 /rss 是订阅目录；本机地址使用上述同步连接器。

Web of Science

在 Clarivate 开发者门户注册应用并申请 Starter API，把密钥保存为 WOS_API_KEY。可按账号情况申请试用或机构方案，不要求先购买新订阅。

公开接口与限流

arXiv、Crossref、PubMed、OpenAlex 和 Semantic Scholar 已有采集代码。arXiv 检索接口受限时尝试官方每日 RSS；Semantic Scholar 使用支持日期范围的批量检索，遇到限流会等待后重试。

需要提高匿名访问额度时，可配置 OpenAlex 的 OPENALEX_API_KEY 或 Semantic Scholar 的 SEMANTIC_SCHOLAR_API_KEY。外部服务仍可能临时限流；其他来源会继续运行。

企业微信与中文精读

企业微信群机器人地址保存为 WECHAT_WORK_WEBHOOK_URL。推荐优先选择 CNS 子刊，同层级侧重大模型与智能体；核心和扩展阅读均须具备七部分中文精读，并注明依据全文还是摘要。

已整理的精读会持续复用。为后续新论文自动生成精读，请设置 LLM_API_KEY，可同时设置 LLM_BASE_URL 和 LLM_MODEL。每次运行最多尝试生成核心与扩展名额总数的解读，默认十篇。未配置模型、生成失败或资料不足的论文保留在数据候选库，不用占位文字补足推荐数量。

通过本地工具保存密钥

也可在项目目录运行以下命令，按提示输入密钥。输入不会回显，工具直接保存到 GitHub Actions，不写入公开网页。

python -m tools.configure --set SERPAPI_API_KEY

本地运行使用被 Git 忽略的 .env；GitHub Actions 使用仓库 Secrets，两者分别配置。
