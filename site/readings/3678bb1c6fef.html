Used car condition-value joint evaluation method based on multiagent LLM decision tree collaboration

公开摘要

This research investigates a multi-agent big language model decision tree collaboration-based used automobile conditionvalue joint evaluation approach. All kinds of data, including vehicle age, mileage, maintenance records, inspection reports, accident history, market pricing, and vendor details, are arranged in this manner. A pricing agent calculates the market value, a risk agent modifies hidden-loss factors, an explanation agent produces reviewable evidence, and a condition agent retrieves vehicle-state evidence. The reasoning route is constrained by a decision tree, and rather of producing free-form text, the result value adheres to interpretable constraints. The suggested approach increased condition-grade consistency from 81.6% to 89.2%, lowered high-risk missing instances by 6.1%, and decreased mean absolute valuation error from 8.7% to 5.4% in a simulated used automobile transaction dataset. According to the aforementioned findings, decision-tree restrictions and cooperative agents can improve the valuation's interpretability and stability.
