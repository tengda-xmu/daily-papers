当搜索成为记忆：以自演化技能加速机器人设计发现

When Search Becomes Memory: Accelerating Robot Design Discovery with Self-Evolving Skills

Yunfei Wang, Xiaohao Xu, Yang Li, Xiaonan Huang
EMNLP 2026

机器人形态优化通常只保留优胜设计，昂贵仿真中的失败原因与结构经验难以复用。本文提出AUTO-ROBOTIST，以结构原型、正负规则和评估观测构建显式技能库，结合LLM定向修改与遗传变异持续搜索。七项二维仿真任务显示，该方法改善冷启动搜索，并支持从5×5向10×10迁移；带参考迁移六项超过GA、一项持平。其价值在于可审计的设计记忆，而非已验证的实体部署能力。

研究问题

本文关注的不是能否再生成一个高分机器人，而是昂贵评估能否留下可迁移知识。每次适应度查询都需训练控制器，传统种群难以显式保存接触、支撑和失效经验。作者要求记忆兼具抽象性、证据依托与可编辑性，以应对设计尺度改变后的重新搜索。

方法与路线

系统以L1结构原型、L2正负规则、L3评估观测组织技能；检索后引导LLM修改精英父代，同时保留GA探索。候选经合法性检查和PPO评估，再通过ADD、DIAGNOSE、MERGE更新记忆。跨尺度仅导入L1与L2，避免把源尺度观测冒充目标证据。

创新与比较

创新重点是把搜索经验变为可检查、可修订的显式设计理论，而非更新LLM权重或直接放大优胜形态。规则描述功能部件间的支撑关系，并保留负面模式及来源。解读：其新意主要体现为证据关联记忆与进化搜索的系统结合，不等于提出新的物理定律。

证据与发现

七任务冷启动终点均超过所列GA，平均收敛加速比为1.66；该指标衡量评估次数而非运行时间。带参考迁移六项超过GA、一项持平，Carrier增益为5.84。Pusher取消GA变异下降24.0%，说明技能提案仍需探索路径；这些结果属于描述性比较。

局限与边界

证据限于二维EVOGYM与固定PPO协议，不能确立三维或实体性能。主要设置仅三种子，消融只覆盖两任务，联合移除L2与L3不能分辨各自贡献；模型版本和硬件披露也不完整。逐页记录未发现原文件缺项，已纠正的提取错误不构成公式缺失。

方向关联

解读：与结构设计最直接的联系，是把承载路径、接触界面及执行器支撑转为可复用关系。对可靠性研究，负规则和观测追溯可启发失效知识管理；对智能运维，可类比检修经验库。但论文没有运维任务、故障诊断指标或实体可靠性试验，不能据此宣称应用有效。

后续研究建议

建议先在结构优化任务复现技能库与GA混合搜索，分别消融正规则、负规则和观测示例，并增加匹配预算的多种子比较。进一步加入规则冲突处理、置信度校准和扰动压力测试，区分仿真偶然成功与稳健规律；实体迁移前设置人工审查和独立安全约束。

阅读建议

推荐作为结构设计与证据驱动智能体研究的方法论文重点阅读，尤其关注失败规则、跨尺度迁移及组件消融；不宜作为智能运维或硬件可靠性已获验证的依据。

查看公开摘要

Large language models (LLMs) are increasingly used as proposal generators for evolutionary robot design, yet most loops remain memoryless: simulator results shape the next population but are not preserved as reusable design knowledge. We present Auto-Robotist, a self-evolving LLM agent that distills morphology-search traces into an explicit natural-language skill library. Each skill stores a structural archetype, evidence-grounded positive and negative rules, and the evaluated designs that support them, making design memory inspectable rather than implicit in a population. During search, the agent retrieves skills to condition LLM edits of elite bodies while retaining a Genetic Algorithm (GA) mutation path for exploration; after evaluation, it updates the library through Add, Diagnose, and Merge. Across seven EvoGym tasks spanning locomotion, traversal, and object interaction, Auto-Robotist improves cold-start 5\times5 search and transfers learned skills to 10\times10 design spaces, where reference-conditioned transfer outperforms or matches GA on every task when averaged across seeds. These results suggest that LLM agents can convert expensive physical evaluations into reusable, auditable design principles. Our code is publicly available at https://github.com/wangyf9/Auto-Robotist.
