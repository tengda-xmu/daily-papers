SecOPD：通过在策略蒸馏缓解自适应提示注入

SecOPD: Mitigating Adaptive Prompt Injections by On-Policy Distillation

Yibo Peng, Long Lian, David Wagner, Sizhe Chen
EMNLP 2026

本文研究智能体处理外部数据时的间接提示注入防御。作者提出SecOPD：学生模型在受攻击输入下生成回答，冻结的初始化教师使用对应的干净输入逐词元评分，以细粒度信号更新学生。 在所评估的SEP PISmith攻击中，其攻击成功率为9.0%，对比Meta-SecAlign的94.0%；AgentDojo结果显示一定的工具调用场景迁移能力。 方法仍依赖可信输入边界，且不能保证抵御未来攻击。

研究问题

论文关注良性用户任务依赖不可信外部数据时，攻击者如何通过数据中的指令改变模型行为。作者认为，序列级反馈难以区分同一回答中完成用户任务与服从注入的不同片段，因此可能限制防御微调对混合回答的学习。

方法与路线

SecOPD为同一任务构造干净输入和受攻击输入，让学生在后者上采样回答，冻结的初始化教师则在前者下评价相同生成前缀和词元。教师与学生的词元对数概率之差形成停止梯度的优势信号，用于更新学生适配器。

创新与比较

作者将原用于效用提升的在策略蒸馏用于提示注入防御，以干净上下文中的初始化模型提供跨上下文词元反馈，而非给整条回答分配统一安全标签。训练无需外部安全评判器或任务专用奖励模型；这不同于实验中用于评价的评判器。

证据与发现

在分别训练攻击者的SEP PISmith评估中，SecOPD攻击成功率为9.0%，Meta-SecAlign为94.0%，GRPO为61.2%。AgentDojo中三者分别为4.7%、5.5%和0.7%；SecOPD七项任务平均效用为88.1%，与未防御模型相同。

局限与边界

方法仅针对用户指令良性而外部数据恶意的间接注入，并假设可信边界明确；未来攻击仍可能突破防御。 评判规则可能压低阳性结果，基线注入分布及部分评估上下文长度亦不完全相同。 核对记录未报告原文件缺项。

后续研究建议

建议在目标智能体场景中构造配对干净与受攻击输入，并针对各防御分别评估自适应攻击，同时报告正常任务成功率和受攻击任务成功率。还应控制基线训练分布与上下文长度，并审核评判器漏判；这些是研究建议，不是作者已完成的验证。

Prompt injection is listed as the #1 threat to AI agents. When an agent accesses external data from websites, files, or emails, an attacker may inject a prompt into the data, saying, "Ignore all prior instructions and perform ." To prevent arbitrary manipulation of agents, defenders try to train secure LLMs, which, however, still suffer from near 100% attack success rates (ASRs) against adaptive prompt injections. We note that this is because existing defensive fine-tuning recipes rely on sequence-level feedback signals (in DPO or GRPO). Treating an entire output equally prevents the model from learning precisely which output tokens are insecure. In this paper, we propose Secure On-Policy Distillation (SecOPD) that provides token-level feedback to guide defensive fine-tuning. The LLM receives an injected sample and produces a rollout, whose tokens are scored by the initialization model given the corresponding clean input. With more fine-grained training signals, our defended Qwen3.6-27B achieves a 9.0% ASR against the SoTA PISmith adaptive prompt injections, compared to 94.0% for the prior SoTA, Meta-SecAlign. The obtained security generalizes to domains completely unseen in training: in agentic tool calling, SecOPD achieves a 4.7% ASR compared to 5.5% for Meta-SecAlign.
