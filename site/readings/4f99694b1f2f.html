【摘要】论文针对现有大语言模型智能体复现评估依赖大量人工整理与评价、难以扩展的问题，提出 ReproRepo 框架，利用人类提出的 GitHub issues 作为真实复现障碍的自然监督。作者基于主要会议的 1,149 篇近期机器学习论文评估四种前沿模型—智能体配置。最佳配置在约 90% 的论文中发现至少一个与人工报告障碍语义相关的问题，但准确定位仍可能不足。上述结论仅依据摘要。[摘要]

研究问题

【摘要】论文关注如何规模化评估大语言模型智能体对科研结果复现的辅助能力。现有基准虽已开展此类评估，但数据整理和评价依赖大量人工工作，因而难以扩展；作者将论文与发布代码中的真实复现障碍作为评估对象。[摘要]

方法与路线

【摘要】ReproRepo 利用人类提出的 GitHub issues，为真实复现障碍提供自然形成的监督信号。作者基于主要会议的 1,149 篇近期机器学习论文实例化该框架，并评估四种前沿模型—智能体配置；摘要未说明具体匹配或评分流程。[摘要]

创新与比较

【摘要】所提出的框架将人类报告的仓库问题用于复现评估，旨在降低对大规模人工数据整理和评价的依赖，并支持可复用、可扩展的评估。其价值在于利用已有问题记录，但仅凭摘要无法判断相对既有工作的完整创新边界。[摘要]

证据与发现

【摘要】研究中表现最好的配置 Codex with GPT-5.5，在约 90% 的研究论文中至少找出一个与人类报告障碍语义相关的问题。分析还指出，智能体擅长发现可见故障和识别正确语义区域，但准确定位仍可能不足；摘要未给出其他配置的具体结果。[摘要]

【摘要】作者明确指出智能体在障碍的准确定位方面仍可能不足。摘要报告的是与人工问题语义相关的发现，并未说明每项发现均准确定位，也未交代数据筛选、问题覆盖范围及评估误差等细节；因此无法据此判断这些方面的具体影响。[摘要]

利用仓库中人类报告的问题评估智能体，可为智能运维中的真实故障发现与评测提供类比；语义区域识别和准确定位之间的差别，也值得可靠性研究关注。但摘要的直接研究对象是机器学习论文的代码复现，未涉及结构设计应用。[摘要]

Reproducing research results from papers and released code is central to scientific progress. Existing works have introduced benchmarks to evaluate whether LLM agents can assist with reproducibility, but they are difficult to scale due to their reliance on substantial manual effort for data curation and evaluation. We introduce ReproRepo, a scalable framework for reproducibility evaluation that leverages human-raised GitHub issues as naturally occurring supervision on realistic reproduction blockers. We instantiate ReproRepo on 1,149 recent machine learning papers from major conferences and evaluate four frontier model-agent configurations. Our results show that LLM agents, even without executing code, can identify many real-world reproducibility problems from paper-repository pairs: the best agent in our study, namely Codex with GPT-5.5, surfaces at least one semantically related human-reported blocker for \sim90% of papers in the study. Further analysis shows that agents are particularly effective for surfacing visible failures and identifying the right semantic region, but may still be insufficient in exact localization. ReproRepo can serve as a reusable, scalable framework for future evaluations of LLM agents on real-world reproducibility auditing. Our code is released at https://github.com/LithiumDA/ReproRepo.
