TimelineAgent：基于大语言模型的多文档查询中心事件时间线抽取框架

TimelineAgent: An LLM-based Framework for Query-Centric Event Timeline Extraction Across Multiple Documents

Qingkai Min, Yunxin Bao, Yifeng Lu, Zhenyu Feng, Yulong Chen, Andreas Vlachos, Yue Zhang
EMNLP 2026

论文研究如何根据实体、方面或种子事件查询，从多篇文档抽取并组织事件时间线。作者提出 TimelineAgent，将候选事件识别、相关性匹配、时间锚定、资格过滤及跨文档共指等步骤交由多阶段智能体处理，并以原子技能库和目标导向协议组织推理。 在构建的三类查询基准上，DeepSeek-V3 版本的 F1 分别为37.9、42.9和33.1；结果显示任务仍具挑战，推理成本也值得关注。

研究问题

论文提出查询中心跨文档事件时间线抽取任务 QUEST：从文档集合中筛选与查询有关的事件，确定其时间并合并共指提及。实体、方面和种子事件查询关注的信息不同，因而需要同时处理语义、论元、因果和时间等异构特征。

方法与路线

TimelineAgent 依次进行句子过滤、候选事件检测、查询相关性匹配、时间锚定、资格过滤和跨文档事件共指。各阶段调用句法、语义、论元、事实性、时间及因果原子技能；编排协议根据推理子步骤和查询类型选择技能组合与配置。

创新与比较

作者的主要设计是把任务无关的事件特征建模与查询、阶段相关的推理解耦：原子技能以受约束提示模块实现，返回结构化中间结果；目标导向协议再按需要组合技能。作者还基于已有数据和新增标注构建覆盖三类查询的评测基准。

证据与发现

DeepSeek-V3 版在实体、方面和种子事件查询上的 F1 分别为37.9、42.9和33.1。去除技能与协议或合并为单阶段均使性能下降；用金标准替换检测、匹配及过滤后，三类 F1 分别升至67.6、69.8和71.4，表明前期事件选择值得重视。

局限与边界

整体性能仍约为30%—40% F1，完整推理约需10小时且受批处理配置影响；大规模 SFT 在方面查询上也超过 Qwen3-32B 版框架0.6 F1。 当前逐页核对记录未报告原文件缺项；P7数值粘连和P9公式层级错误均为已纠正的提取错误，并非原文件缺项。

方向关联

解读：跨文档事件筛选、时间锚定与共指合并可为智能运维中的事故记录梳理提供方法参照，事实性过滤也有助于区分已发生事件与否定表述。 但本资料未展示运维、结构设计或可靠性数据上的实验，不能据此认定实际迁移效果。

后续研究建议

建议以运维日志和故障报告构建带时间、设备实体及事件共指标注的小规模基准，分别评估事件选择、时间锚定和最终时间线，并记录推理耗时。作者另提出细粒度技能编排、大小模型混合及人机协作标注作为未来方向，这些方案在资料中尚未验证。

阅读建议

Query-centric cross-document event timeline extraction aims to construct event timelines from multiple documents under diverse query focuses. The task is very challenging due to the heterogeneous event modeling and reasoning requirements arising from both the intrinsic complexity of cross-document timeline construction and the diversity of query focuses. In this paper, we propose TimelineAgent, an LLM-based multi-agent framework featuring a multi-stage reasoning workflow, where heterogeneous event features are organized into reusable skills and orchestrated through a goal-oriented protocol. To facilitate evaluation, we construct a benchmark covering diverse query focuses. Experimental results show that TimelineAgent consistently outperforms existing methods, offering a practical framework for complex real-world timeline construction.
