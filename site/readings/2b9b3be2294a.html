SafeRx-Agent：知识支撑的安全可解释用药推荐多智能体框架

SafeRx-Agent: A Knowledge-Grounded Multi-Agent Framework for Safe and Explainable Medication Recommendation

Xinyu Wang, Hanwei Wu, Zhenghan Tai, Sicheng Lyu, Qincheng Lu, Ziyu Zhao, Jijun Chi, Jingrui Tian, Xiao-Wen Chang, Ziyang Song

本文研究重症患者的细粒度药物集合推荐，将预测粒度设为ATC-L4，并以多专科智能体结合临床知识生成候选，再通过全局评议和安全验证形成可追溯结果。作者在MIMIC-III和MIMIC-IV上报告了预测与安全性结果，并通过消融和集合大小匹配分析各模块作用。结论受限于安全知识覆盖、回顾性评估和未建模剂量等因素，不能直接视为临床安全性证明。

研究问题

论文针对电子病历用药推荐中的两类问题：传统方法主要预测结构化药物代码，推理时证据支撑有限；大模型虽能利用临床上下文，却可能缺乏安全核验。作者还指出，粗粒度药物分类会掩盖亚组差异并高估已记录的相互作用风险。

方法与路线

系统根据诊断信息将患者路由至相关专科专家及常开支持治疗专家，各专家结合病历摘要、既往就诊理由和MEDI适应证生成ATC-L4候选；全局评议合并去重，再由安全矩阵检索风险并结合患者背景裁定保留或移除。

创新与比较

作者提出细粒度ATC-L4药物集合预测，并将专科分工、适应证知识、跨专家评议和可追溯安全核验组合为统一流程。解读：其可借鉴之处是把风险检索与受限裁定分开，而不是要求模型在开放生成时自行承担全部安全判断。

证据与发现

在MIMIC-IV的Gemma3设置下，过滤前完整方法F1为0.388，调用次数匹配的通用代理为0.335。逐病例集合大小匹配时，VERIFY的DDI-B为0.3695，最强删除控制为0.5479；作者据此认为安全收益不只来自减少预测数量。

局限与边界

安全资源未覆盖的关系默认未被标记，验证与评估共用资源；研究未建模剂量、途径、频率和疗程，且仅作回顾性离线评估。监督基线和免训练方法的测试范围不同，不宜作配对比较。逐页核对记录未报告已核实的原文件缺项。

方向关联

解读：面向智能运维或可靠性研究，专科路由可类比按故障领域分派分析模块，证据检索与受限裁定可类比告警核验和处置审查；药物安全指标与临床数据本身不能直接证明这些工程场景有效。本文也未直接研究结构设计。

后续研究建议

建议先在同一病例集合上开展更严格的基线配对，再引入独立药师或医生盲审，检验风险标记和保留、移除决定的临床正确性；进一步补充前瞻验证及剂量等信息。建议核查专家激活人数与案例图注中的不一致。

Medication recommendation predicts medications for patient visits, but existing methods still face two key challenges. At the model level, traditional drug recommendation methods only predict structured drug codes with limited evidence grounding, while LLM agents can use richer clinical context but may lack safety verification and traceability. At the task level, existing benchmarks often use broad medication categories, which ignore subgroup-level safety differences and can lead to risk overestimation. We introduce the first fine-grained medication recommendation setting based on fourth-level ATC code generation. We propose Safe Prescription Agent (SafeRx-Agent), a knowledge-grounded multi-agent framework that uses patient context, external clinical knowledge, and safety verification to recommend traceable medication sets. Experimental results on MIMIC-III and MIMIC-IV datasets show that SafeRx-Agent improves fine-grained medication prediction accuracy while controlling drug interactions, contraindications, and medication set size. Code accompanying this work is available at https://github.com/HWu3150/SafeRx-Agent/tree/main.
