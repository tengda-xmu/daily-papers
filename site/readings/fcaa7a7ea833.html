RoleKV：面向大语言模型智能体上下文年龄与重要性倒置的角色感知键值缓存管理

RoleKV - Role-Aware KV Cache Management for the Inverted Age-Importance of LLM Agent Context

Eashan Dash, Arun Ramachandran, Prakash Raghavendra
EMNLP 2026

论文研究多轮智能体推理中，按最近使用情况驱逐键值缓存可能误删持续重要的系统提示和工具输出的问题。作者测量不同语义角色的注意力衰减，提出免训练的 RoleKV，通过角色标注、生命周期阈值和优先级评分决定缓存块去留，并在 vLLM 与 LMCache 中评估。实验报告了抢占、PCIe 流量和延迟收益，但收益依赖内存压力及工作负载；部分排序与最优性论证仍需审慎核对。

研究问题

多轮智能体不断累积系统提示、任务指令、推理和工具结果，缓存块的复用价值并不只由新旧决定。作者发现较早的系统和工具内容可能持续受到关注，而较新的推理内容衰减较快；基于近期性的驱逐因此可能造成重复预填充或数据搬运。

方法与路线

RoleKV 首先依据模板标记为缓存块分配语义角色，再用探测得到的角色衰减常数确定生命周期阈值。超过阈值的候选块按衰减、角色权重和动作预测增益组成的分数排序，低分优先驱逐；系统块受保护，策略在系统层管理块的位置。

创新与比较

作者将跨轮次角色注意力动态引入缓存保留决策，而非仅以块年龄或步骤位置作为代理信号；同时采用确定性标注器和按工作负载校准的衰减曲线。解读：其主要贡献在系统策略与实测信号的结合，并非改变模型注意力计算或提出新的模型训练方法。

证据与发现

作者报告 WebArena 紧预算下抢占减少64.3%；GAIA 的 Llama-70B、100轮配置下，GPU 命中率为52.1%，相对 LRU 加速1.41倍。三个模型的 LMCache 平均 PCIe 流量分别下降18.2%、22.5%和26.4%；这些结果属于不同配置，不能合并为同一实验。

局限与边界

收益集中在特定内存压力范围，短轨迹未评估无共享前缀情形；新模板需要标记词表，新工作负载可能需要重新探测。解读：最优排序证明包含初始注意力幅度，而实际评分未显式包含该项，且正文与部分表格存在数值不一致，结论需谨慎使用。

方向关联

解读：对智能运维中的多智能体服务，本文可作为缓存资源管理和推理成本监测的参考：将请求内容类型与复用行为关联，再观察命中率、抢占和传输流量。论文针对的是大模型服务系统，并未直接验证其对物理结构设计或工程可靠性分析的效果。

后续研究建议

建议在目标运维工作负载上先测量角色注意力与复用周期，再对无共享前缀、不同并发和预算开展受控比较；同时分别核对输出一致性及端到端成本。建议复核评分中初始幅度和动作增益对理论排序的影响，并检查模板标记变化带来的误分类风险。

阅读建议

查看公开摘要

When serving LLM agents in production, the KV cache grows over turns, and mainstream serving engines (e.g., vLLM) rely on least recently used (LRU) eviction to manage memory pressure. While LRU is well-understood for OS pages and single-turn LLM serving, its behavior on agent workloads remains underexplored. We present an inverted age-importance phenomenon in agent workflows, where the oldest KV blocks (system prompts, tool outputs) are the most persistently attended, while the .newest blocks (chain-of-thought reasoning) decay fastest. As a result, recency-based eviction systematically discards the wrong blocks in agent workloads, producing two distinct overheads: (1) wasted prefill work on preempt-discard engines, and (2) wasted PCIe bandwidth on CPU-offload engines. We propose RoleKV, a training-free, lossless eviction policy that evicts KV blocks based on their semantic role in agent workflows. A lightweight Role Tagger assigns each block to a semantic role, and RoleKV then evicts by role-aware decay rather than recency. Unlike model-level KV compression methods that incur quality loss, RoleKV is a system-level policy that decides where blocks reside (GPU vs. CPU/disk), without affecting model outputs. RoleKV cuts preemptions by up to 64.3%, PCIe traffic by up to 63.8%, and improves end-to-end latency by up to 1.41× on 8B-70B models, with gains that grow on longer agent traces and persist on multi-GPU setups. This recasts KV eviction in production LLM serving from a recency problem to a role-aware retention problem.
