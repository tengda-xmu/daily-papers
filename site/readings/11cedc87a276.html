T-MAP：利用轨迹感知进化搜索对大语言模型智能体开展红队测试

T-MAP: Red-Teaming LLM Agents with Trajectory-aware Evolutionary Search

Hyomin Lee, Sangwoo Park, Yumin Choi, Sohyun An, Seanie Lee, Sung Ju Hwang
EMNLP 2026

论文研究大语言模型智能体在多步工具调用中产生的安全风险，提出轨迹感知进化搜索方法 T-MAP。 方法结合风险类别与攻击风格档案、跨轨迹诊断和工具调用图，以实际行动完成程度评价攻击。 作者报告其在五种 MCP 环境中的平均攻击实现率为57.8%，并通过消融、多模型及人工评价补充证据。 结果受沙箱环境和攻击者模型等条件限制，不能直接等同于真实部署风险。

研究问题

论文关注传统红队测试难以覆盖的智能体风险：有害后果可能由规划、连续工具调用和环境反馈共同产生，而非单轮文本直接显现。 作者因此把评估重点转向工具执行是否完成预期有害行动，并区分拒绝、执行错误、部分完成和完全实现。

方法与路线

T-MAP 按风险类别与攻击风格维护二维精英档案，保存候选提示及其轨迹。 每轮从父轨迹提取成功因素、从目标轨迹诊断失败原因，结合记录工具转换结果的有向图生成候选；执行后由裁判评估并更新档案与图。

创新与比较

相对仅依据文本反馈或单个单元经验进行提示改写，作者将跨单元成功与失败诊断和工具调用图结合，分别提供提示层面及行动层面的搜索信号。 解读：其方法特点在于复用跨轨迹经验，同时显式维护工具转换结果，而非仅追求单个成功提示。

证据与发现

主实验中，T-MAP 在五种 MCP 环境均取得最高攻击实现率，平均为57.8%。 消融实验中，移除工具调用图使 L3 从58.40%降至45.71%；移除交叉诊断使拒绝率从11.93%升至15.63%。 三种随机种子实验也支持其相对优势，但不同表格的结果应分别引用。

局限与边界

作者指出实验仅覆盖五类 MCP 服务器，且在沙箱中进行，现实权限检查等保护可能限制结果外推；攻击者模型的安全对齐也会影响效果。 人工标为 L3 的评价中有29.8%被模型判为 L2。 核对记录未报告原文件缺项；所列编码提取错误已纠正，不构成公式缺失。

方向关联

解读：对采用工具调用智能体的智能运维，本文的轨迹分级和转换图可启发审查权限变更、文件操作及跨工具链的风险，而不只检查回复文本。 但资料未验证其在工业运维中的效果，也未提供结构设计或工程可靠性领域的直接实验。

后续研究建议

建议在授权沙箱内构建贴近实际运维流程的测试集，区分工具调用成功、关键步骤完成与真实业务后果，并比较权限确认等防护措施的影响。 建议增加人工复核与多攻击者模型重复实验，报告裁判分歧和结果波动，而非仅依赖单一平均指标。

阅读建议

建议从事工具调用智能体安全评估的读者重点阅读：论文不仅提供可复核的搜索框架和轨迹级指标，还报告消融、重复实验与人工评价；但迁移到实际业务前应关注沙箱和裁判可靠性限制。

查看公开摘要

While prior red-teaming efforts have focused on eliciting harmful text outputs from large language models (LLMs), such approaches fail to capture agent-specific vulnerabilities that emerge through multi-step tool execution, particularly in rapidly growing ecosystems such as the Model Context Protocol (MCP). To address this gap, we propose a trajectory-aware evolutionary search method, T-MAP, which leverages execution trajectories to guide the discovery of adversarial prompts. Our approach enables the automatic generation of attacks that not only bypass safety guardrails but also reliably realize harmful objectives through actual tool interactions. Empirical evaluations across diverse MCP environments demonstrate that T-MAP substantially outperforms baselines in attack realization rate (ARR) and remains effective against frontier models, including GPT-5.2, Gemini-3-Pro, Qwen3.5, and GLM-5, thereby revealing previously underexplored vulnerabilities in autonomous LLM agents. Code is available at https://github.com/pwnhyo/T-MAP.
