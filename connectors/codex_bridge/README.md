# 本机 Codex 论文助手

直接使用本机 Codex 的 ChatGPT 登录和账号额度，不需要 `OPENAI_API_KEY`。连接器已验证 `codex-cli 0.155.0-alpha.16.3`、`0.155.0-alpha.16` 和 `0.154.0-alpha.6.2`。按完整版本号匹配，不自动放行未验证的 alpha 版本。

2026-09-24 已比对两个 `0.155` 安装版本生成的实验性协议（两者相同），并实测论文引用问答。`0.155.0-alpha.16.3` 另外验证了模型切换、图片输入、进程重启后的会话恢复和中断；创建与恢复线程均返回 `paper-reader`、只读沙箱、禁止工具网络访问和 `never` 审批策略。运行时仍检查这些权限，版本匹配不会跳过检查。

Codex 自动升级后若提示“版本尚未验证”，更新本机仓库的连接器代码，再停止并重新启动论文助手；只刷新网页不会重载正在运行的 Python 程序。重启保留已上传 PDF、翻译缓存和历史对话；已记住的浏览器自动恢复连接。此错误不表示 ChatGPT 登录失效。

## Windows 使用

1. 双击仓库根目录的 **启动论文助手.cmd**。首次启动会安装此连接器的 Python 依赖，随后打开本机页面并自动配对。
2. 在本机页面选择论文，即可总结、提问、翻译或解释图片。对话侧栏顶部和本机首页均有“复制配对码”按钮，成功时显示“已复制配对码”。浏览器不允许自动复制时，会显示并选中配对码，可按 `Ctrl+C`（Mac：`⌘C`）手动复制；也可直接点击“手动复制”。刷新后，已配对的本机页面会重新读取本次启动的配对码，无需关闭侧栏。
3. 如需在公开网站的侧栏使用，点击论文下方的 **Codex 对话**，首次粘贴本机页面的配对码。默认勾选 **记住此浏览器，下次自动连接**；之后刷新、新开标签页、关闭浏览器再打开或重启本机助手，均自动恢复连接。首次访问可能需要允许浏览器连接本地网络。
4. 若浏览器阻止在线网站连接本机，使用 **在本机打开论文助手**。此入口与公开页面连接的是同一份对话记录。
5. 双击 **停止论文助手.cmd** 停止服务；不会退出 VS Code 中的 Codex 登录或终止正在开发网站的对话。

本机入口是 `http://127.0.0.1:43127/`。电脑和连接程序必须运行，仅能从这台电脑使用；不自动向局域网或互联网开放端口。其他电脑/手机仍可正常阅读公开网站。

在线网站与本机页面各自记住一次授权。侧栏显示 **已记住此浏览器 · 自动连接**，点击 **取消记住** 会撤销该浏览器授权及已恢复的短期会话，下次需重新配对。清除浏览器网站数据、使用不同浏览器或连续 90 天没有恢复连接时也需重新配对。浏览器不允许保存数据时会明确提示，仍可使用当前连接。

若先打开网页再启动助手，已记住的浏览器会在侧栏保持打开时自动重试（约 8 秒）；回到该页面时也会尝试恢复。认证过期只重试已被本机拒绝、尚未执行的请求；已发送的模型生成遇到网络断开时不会自动重发。

脚本也可运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools/start_codex.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File tools/stop_codex.ps1
```

如登录过期，先在本机终端运行 `codex login`，再点击连接。不在网页里收集 ChatGPT 密码。若找不到 Codex，安装 CLI 或 VS Code 扩展；可用本机环境变量 `PAPER_CODEX_EXE` 指定可执行文件。

Windows 下，连接器会为自己的 Codex 子进程沿用系统 HTTP/HTTPS 代理，避免首次连接反复超时后才恢复。已有 `HTTP_PROXY`、`HTTPS_PROXY` 或 `ALL_PROXY` 环境配置优先，回环地址保持直连；不会修改全局 Codex 配置或把代理地址写入网页、日志。修改系统代理后，重启论文助手生效。全文长度、模型分析与服务负载仍会影响首字和总耗时。

## 资料及回答

- **原文与对话并排**：桌面默认打开左侧原文阅读器，右侧保留论文对话；中间分隔条可拖动或用方向键调整，“收起 / 原文阅读”切换显示。手机使用顶部“原文 / 对话”标签。支持连续翻页、输入页码和缩放，点击回答中的 PDF 页码可定位原文。
- **划词操作**：在单页选中文字，可英译中、中译英或送入右侧继续提问；PDF 同时支持高亮、下划线和删除线。翻译使用当前所选 Codex 模型；网页全文也支持选段翻译。扫描页没有可选择文字，可用画线、画笔、笔记或右侧截图翻译。
- **修改与导出批注**：画线、手绘、点选位置添加笔记；“批注”中修改笔记、颜色或删除，支持撤销 / 重做。每次编辑自动保存本机 SQLite，按论文和 PDF 哈希隔离，刷新 / 重启可恢复。更换 PDF 时保存原版本批注；重新载入相同文件仍可读取。多页面修改冲突不会覆盖，可备份本页 JSON 后重新载入。导出批注 PDF 保留原页数、图表、文字和版式，将标记写为标准 PDF 注释，原文件不改写。此功能编辑的是批注，不直接改写论文正文；下载副本中的笔记可在支持注释的 PDF 阅读器查看。
- **预览实现**：使用随站点打包的 [Mozilla PDF.js 6.3.289](https://github.com/mozilla/pdf.js/releases/tag/v6.3.289)，版本、源地址及 SHA-256 记录于 `tools/assets/vendor/pdfjs/version.json`，Apache 2.0 与字体 / 解码器许可随包保留；`python tools/vendor_pdfjs.py` 可校验并重新获取固定版本。PDF 通过已配对的本机接口加载，不上传到第三方查看器，也不执行文档脚本。按需渲染附近页面；预览、批注和导出不调用 Codex。清除论文资料会同时删除其所有版本的批注。
- **编辑已发送的问题**：点击问题下方“编辑”，在原位置修改后“保存并重新发送”，或取消。新版本从该问题继续生成，原问题、回答及其后续对话保留；左右箭头和版本编号可切回。原截图、翻译方向与范围沿用，模型使用当前选择。下方输入框的未发送草稿不受影响；论文资料已更换时，需新建提问，不能用新资料改写旧版本。
- **重新生成与重试**：回答下方“重新生成”会为原问题新增一个回答版本，失败或停止时显示“重试”。选择某个回答版本后，可继续该版本的后续对话；切换不调用模型。完整译文重新生成会重新翻译，未完成译文重试沿用该次已保存的进度。旧版译文文件保留。
- **阅读与发送**：用户问题显示为右侧气泡，回答操作放在内容下方。Enter 发送，Shift+Enter 换行；中文输入法选字不会发送。编辑框可按 Ctrl+Enter 保存、Esc 取消。向上阅读历史时暂停自动滚动，点击“回到最新回复”重新跟随输出。
- **调整区域大小**：上下拖动阅读区下方的分隔条调整阅读区高度，桌面端可左右拖动侧栏左边缘调整宽度。浏览器会记住尺寸，窗口变小时自动限制在可用范围内；手机支持触摸调整高度。双击对应分隔条恢复默认，也可用 Tab 聚焦后按方向键调整、Enter 恢复。输入区域缩小时可单独滚动，继续访问翻译、导出和发送等操作。
- **模型选择**：连接后，侧栏顶部显示当前 Codex 账号返回的可选模型，默认选中账号默认模型。浏览器会记住你的选择，切换对下一次发送生效，保留当前论文会话；生成中暂不可切换。每条新回答和导出记录标注所选模型，历史旧回答不补写未知的模型。列表每次连接时刷新；此前选择不再可用时，需要重新选择。仅支持文字的模型无法读取配图或扫描页。
- **深入提问**：针对具体问题回答，并给出关键证据、简短分析依据和适用边界。**中英翻译**：选择英译中或中译英，可粘贴原文，也可指定已载入论文的章节 / PDF 页码；按段落给出原文与译文，不自动改做全文总结。
- **全文翻译（保留 PDF 版式）**：载入带文字层的 PDF，点击“翻译并生成 PDF”。按页定位文字区域，在原位置回填译文，直接生成并下载 PDF；页数、页面尺寸、分栏、图像和独立公式保持原样，内嵌公式及上下标以原图保留，文字大小与换行适配原区域。图片内文字不改写。扫描页、缺失公式占位符和译文溢出均明确报错，不生成截断文件。翻译区域逐批缓存，可在相同模型、方向与要求下恢复；生成文件绑定回答，替换资料后仍可下载旧版本。使用固定 PyMuPDF 1.27.2.3，文件及公式图片仅存于本机私有资料目录。
- **全文翻译（文本对照）**：用于原文和译文的连续对照阅读，支持 PDF 或网页全文。每部分最多约 6,000 字符，扫描页逐页提供真实图片；覆盖全部已载入页或段落，不按关键词筛选。保留 P/S 来源编号，导出为重新排版的对照 PDF。
- 每部分成功翻译后自动保存在本机。停止、网络失败或重启后，保持同一份资料、模型、目标语言和补充要求再次开始，已完成部分直接恢复，继续未完成部分。修改资料或这些设置会重新翻译。完整翻译通常比总结耗时更长，界面显示已完成部分数；清除本机记录也会删除翻译缓存。
- **导出 PDF**：对话底部的按钮导出当前论文全部问答；某条回答旁的“导出 PDF”只导出该条回答，适合保存全文译文。直接下载带中文字体、标题、DOI、原文编号和导出页码的 PDF，不需要打开打印窗口；未完成的译文会标为“部分内容”。保留原文/译文阅读顺序，不复刻出版社原版排版。原有“导出对话”仍导出 Markdown。Windows 默认使用系统微软雅黑；Linux 可安装 `fonts-wqy-microhei`，其他环境可用本机环境变量 `PAPER_PDF_FONT` 指定中文 TrueType TTF/TTC 文件。
- 四种模式分别保留当前页面内的输入草稿，切换模式不会把“总结论文”的默认指令带入提问或翻译。
- 生成期间，回答区分别显示本机连接状态、已用时间与最近模型活动。每 15 秒的连接心跳不再算作模型响应；只有实际模型事件更新活动时间。网络重试显示次数，“处理记录”保留提交、重试和生成阶段。这里只展示处理进度与面向读者的分析依据，不传递模型内部推理文本。接口事件依据 [Codex App Server 官方文档](https://learn.chatgpt.com/docs/app-server)。
- 空回答、额度限制或服务异常会给出提示；失败原因保存在本机记录中，没有完成时会恢复输入以便重试。连接连续 45 秒没有数据或心跳时结束等待，模型单轮响应仍受连接器超时限制。
- **上传 PDF / 获取论文 PDF**：两个按钮直接显示在模型选择区下方。“获取论文 PDF”从当前论文的公开地址或出版社声明的 PDF 链接读取文件，成功后显示页数，并用于后续总结、问答和翻译；遇到登录页面、访问限制或非 PDF 内容时提示手动上传，保留已有资料。上传和获取期间显示状态并暂停发送，避免使用尚未就绪的资料。
- 默认只提供摘要、元数据及本站解读；后者明确标为编辑整理，不等于论文原始证据。
- 展开“阅读依据”仍可使用“获取网页全文”。自动获取仅访问已知来源的公开 HTTPS 地址；遇到登录墙、限流或不可确认的正文时返回提示，不绕过访问限制。
- 上传 PDF 最大 20 MB、300 页。原始文件、逐页文本和扫描页图片仅存入 `.local/codex-bridge/documents/`。**分析时，相关文字和图片会交给你账号连接的 Codex 服务，并非离线模型。**
- 扫描 PDF 总结分批提供全部页，每批最多四张；页数较多时耗时和账号额度使用量也增加。提问区已移除独立的 PDF 页码输入框，可直接描述需要分析的章节，或上传目标段落截图。
- `P1` 是 PDF 第 1 页（不是排版中的印刷页号）；`S1` 是网页正文第 1 段。点击回答中的引用可对照提取原文；扫描页仍需对照 PDF，模型引文需要人工核查。
- **上传截图**：输入框下点击上传，也可在提问区 Ctrl+V 粘贴或拖入图片。每次最多 4 张，每张最多 8 MB / 1600 万像素，支持单帧 PNG、JPEG、WebP；上传后可预览和移除。文件实际解码并去除元数据后保存为 PNG，只有所选模型支持图片时才允许发送。截图与本轮问题一同传给 Codex，不替换已载入 PDF；纯截图可不填问题直接发送。
- 截图在本机按论文分别保存，待发送截图可在刷新后恢复，已发送截图随对应历史消息显示。只返回图片编号，不接受任意本机路径；预览同样需要配对授权。截图编号不能跨论文使用，清除该论文记录会同时删除截图。
- “解释配图”优先读取本轮上传截图，没有截图时使用论文的原始配图。“中英翻译”提供 **截图翻译**，直接读取截图中的文字，不需要 PDF。截图引用使用 `[上传截图1]` 等标签，不推测页码或补写模糊文字。
- 更换全文或 PDF 后，新问题建立新上下文，避免旧资料混入；此前对话仍显示在历史中。
- 清除功能删除这篇论文在连接器中的记录和全部上传资料。Codex 自身的会话记录仍由 Codex 管理；不会声称已删除远端或 Codex 原生历史。

## 实现及边界

Python/FastAPI 仅监听回环地址，用八小时 Bearer 会话验证访问并校验 Host/Origin。公开网站地址固定为 `https://tengda-xmu.github.io`。配对码存入被 Git 忽略的私有目录；Windows 启动脚本限制该目录的继承权限，仅授予当前用户和 SYSTEM。在线页面短期令牌保存在当前标签页，本机页面保存短期令牌以支持新窗口；这些令牌在服务重启或八小时后失效。

用户选择记住后，浏览器在自己的 `localStorage` 保存独立的恢复凭证；连接器只保存 SHA-256 哈希、对应 Origin 和有效期。恢复凭证不能直接访问论文接口，只能在原授权 Origin 换取短期会话；最长闲置 90 天，每次恢复续期。它不包含 Codex 登录信息，也不复用配对码。其他网页、错误来源和未配对请求仍被拒绝，恢复失败有频率限制。所有凭证均不进入公开 HTML、日志或仓库。

连接器启动一个独立的 `codex app-server --listen stdio://` 子进程，共享官方登录缓存，但不读取或导出凭据。专用 `paper-reader` 权限仅允许读取空的工作目录、禁止执行工具网络访问；关闭命令、Code Mode、MCP、应用、插件、浏览器、子智能体及记忆等功能开关。线程创建时核验实际权限；所有来自模型的审批请求拒绝，检测到非阅读工具事件则中断。使用账号默认模型与 `medium` 推理强度，避免继承全局 `ultra` 的主动委派行为。浏览器不能指定 RPC 方法、Codex 会话 ID、本机路径或工具权限。

每篇论文映射到自己的线程；连接器 SQLite 保存带版本分支的历史，Codex 提供连续对话与恢复。编辑、重新生成或切换版本时重建线程，只带入所选分支及当前资料版本的历史，避免被替换内容混入；过长的历史会明确截断，不当作论文证据。多页面操作通过当前对话位置校验，过期页面需刷新后重试。旧版平铺记录在首次启动时迁移，保留所有消息与译文文件。对话 PDF / 文本只导出当前所选分支；清除本机记录会删除所有分支。

一次只生成一个回答；请求 ID 防止重复提交，断开或停止会中断生成并保留已收到的文字。重新启动后可恢复历史；本机论文数据需与网站同步。

本地端点提供配对、连接状态、论文列表/历史、SSE 问答、PDF/开放全文、引用查看、停止和清除，不公开通用 Codex RPC。GitHub Actions 只验证代码和发布静态网页，不运行这个服务或获取本机登录缓存。

```powershell
python -m pip install -r connectors/codex_bridge/requirements.txt
python -m pytest tests/test_codex_bridge.py -q
```

官方参考：[App Server](https://learn.chatgpt.com/docs/app-server)、[登录复用](https://learn.chatgpt.com/docs/auth)。App Server 是实验性接口，Codex 更新后可能需要适配。
